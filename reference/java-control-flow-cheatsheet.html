Control Flow Cheatsheet

레슨 0002에서 압축

기본 형태

if (cond) { ... } else if (cond2) { ... } else { ... }

for (int i = 0; i < n; i++) { ... }       // 인덱스 필요할 때
for (Item item : items) { ... }           // enhanced for, 대부분 이걸 씀

while (cond) { ... }
do { ... } while (cond);                  // 최소 1회 실행 보장

classic switch — fallthrough 있음

switch (status) {
    case "DRAFT":
        // ...
        break;   // 빠뜨리면 다음 case로 흘러 내려감
    default:
        // ...
}

statement다 — 값을 반환하지 않고 실행만 한다.

switch expression (Java 14+) — fallthrough 없음

String label = switch (status) {
    case "DRAFT" -> "초안";
    case "SENT" -> "발송됨";
    default -> "알 수 없음";
};

int score = switch (status) {
    case "SENT" -> {
        // 여러 줄 로직
        yield 5;
    }
    default -> 0;
};

expression이다 — 값을 만들어 돌려준다. case 간 fallthrough가 구조적으로 불가능.

선택 기준

상황선택
값을 만들어야 함 (라벨, 점수 등)switch expression
그냥 실행만 하면 됨 (로깅, 부수효과)classic switch 또는 if
