Lambda & Stream Cheatsheet

레슨 0015에서 압축

Lambda 문법

(파라미터) -> 표현식
p -> p.getPrice()            // 파라미터 1개면 괄호 생략 가능
(a, b) -> a + b               // 파라미터 여러 개면 괄호 필수
p -> { return p.getPrice(); } // body가 statement block이면 중괄호 + return

lambda가 인자로 들어갈 수 있는 이유: 받는 타입이 functional interface(abstract method가 정확히 1개인 interface)이기 때문.

Stream pipeline 구조

list.stream()        // source
    .filter(...)      // intermediate — Stream 반환, 체인 가능
    .map(...)          // intermediate
    .collect(...);      // terminal — Stream 아닌 최종 결과, 체인 끝

주요 operation

operation종류받는 functional interface하는 일
filterintermediatePredicate<T>조건에 맞는 것만 남김
mapintermediateFunction<T,R>각 요소를 변환
sortedintermediateComparator<T>정렬
forEachterminalConsumer<T>각 요소에 부수효과
collectterminalCollectorList/Set/Map으로 모음
reduceterminalBinaryOperator<T>전체를 하나의 값으로 누적

패턴 모음

// 필터 + 매핑 + 모으기
List<String> names = employees.stream()
    .filter(e -> e.isActive())
    .map(Employee::getName)
    .collect(Collectors.toList());

// 정렬 (내림차순)
List<Employee> sorted = employees.stream()
    .sorted(Comparator.comparingDouble(Employee::getSalary).reversed())
    .collect(Collectors.toList());

// 합계 — 실무에서 흔한 방식
double total = employees.stream()
    .mapToDouble(Employee::getSalary)
    .sum();

// 합계 — reduce로 직접
double total2 = employees.stream()
    .map(Employee::getSalary)
    .reduce(0.0, (acc, s) -> acc + s);

// 중복 제거 (0009 collections와 연결)
Set<String> departments = employees.stream()
    .map(Employee::getDepartment)
    .collect(Collectors.toSet());

Method reference

Employee::getName은 e -> e.getName()의 축약형. 의미는 완전히 동일하다.

0008/0009와의 연결

functional interface(Predicate, Function, Comparator 등)도 결국 0008에서 배운 interface다 — abstract method가 하나뿐이라 lambda로 구현체를 한 줄에 쓸 수 있는 것뿐이다. .collect(Collectors.toSet())은 0009에서 배운 Set(중복 없음)을 stream 결과로 만드는 방법이다.
