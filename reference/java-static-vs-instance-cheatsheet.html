Static vs Instance Cheatsheet

레슨 0006에서 압축

핵심 구분

instance memberstatic member
속한 곳object (각자 따로)class (전체가 공유, 하나뿐)
부르는 법obj.field / obj.method()ClassName.field / ClassName.method()
this 사용가능불가능 (가리킬 instance 없음)

패턴

public class Ticket {
    private static int nextId = 1;   // class가 공유하는 카운터

    private int id;                  // object마다 따로
    private String subject;

    public Ticket(String subject) {
        this.id = nextId;
        nextId++;
        this.subject = subject;
    }

    public static int getCreatedCount() { return nextId - 1; }
}

static + final = 상수

재대입 불가능. 예: Math.PI. 대입 시도하면 컴파일 에러.

왜 main은 static인가

JVM이 프로그램을 시작할 때 아직 만들어진 object가 없다. object 없이 부를 진입점이 필요해서 static이어야 한다.

Quarkus vs Spring 다리

Panache active record는 Person.findAll()처럼 static method로 쿼리. Spring Data JPA는 repository를 instance로 주입받아 repository.findAll(). Spring Boot 기본값 = 주입받은 instance로 호출.
