원칙

특별한 이유가 없으면 private. 그 member에 필요한 가장 제한적인 레벨을 선택.

패턴

public class Money {
    private String currency;      // 외부에서 직접 못 건드림
    private int amountInCents;

    public Money(String currency, int amountInCents) {
        if (amountInCents < 0) throw new IllegalArgumentException();
        this.currency = currency;
        this.amountInCents = amountInCents;
    }

    public int getAmountInCents() { return amountInCents; }   // getter — 읽기만
    public String getCurrency() { return currency; }
    // setter는 일부러 안 만듦 — immutable 의도
}

왜 field를 열어두면 안 되는가

constructor의 invariant(fail fast)는 field가 private일 때만 계속 유지된다. field가 열려있으면 obj.field = 잘못된값;으로 검증을 우회할 수 있다.

Quarkus vs Spring 다리

Panache entity는 보통 field public (active record). Spring Data JPA는 거의 항상 private + getter/setter. Spring Boot 기본값 = private.
