물려지는 것 / 안 물려지는 것

member상속 여부
public / protected물려짐
package-private (같은 package)물려짐
private안 물려짐 (public/protected getter로만 접근)
constructor안 물려짐 — super(...)로 직접 호출

패턴

public class Notification {
    protected String recipient;
    public Notification(String recipient) { this.recipient = recipient; }
    public void send() { System.out.println("일반 알림"); }
}

public class EmailNotification extends Notification {
    private String subject;

    public EmailNotification(String recipient, String subject) {
        super(recipient);           // 첫 줄에 와야 함
        this.subject = subject;
    }

    @Override
    public void send() {            // signature 동일 = overriding
        System.out.println("이메일 " + subject);
    }
}

polymorphism

List<Notification>에 여러 subclass를 섞어 담고 send()를 부르면, 선언 타입이 아니라 실제 object 타입의 override된 method가 실행된다 (virtual method invocation). instanceof 분기 없이 다형적으로 처리 가능.

protected의 위치

private(같은 class만) < protected(같은 class + subclass) < public(전체). subclass 접근이 필요하면 protected.

Quarkus/Spring 다리

IllegalArgumentException extends RuntimeException extends Exception — 이미 써본 예외 클래스도 상속 계층이다. Spring의 @ControllerAdvice도 이 계층을 이용해 예외 계열 단위로 처리한다.
