판단 기준

"If a client can reasonably be expected to recover from an exception, make it a checked exception. If a client cannot do anything to recover from the exception, make it an unchecked exception." — Oracle Java Tutorials — Unchecked Exceptions

try / catch / finally

try {
    Employee e = service.findByIdOrThrow(id);
} catch (EmployeeNotFoundException e) {
    System.out.println("처리: " + e.getMessage());
} finally {
    System.out.println("항상 실행됨");
}

try/catch 실행 모델

catch는 "실패하면 대신 이걸 해라"는 대안 로직이 아니다. try 안에서 실패한 바로 그 코드를 처리하는 곳이다. 그래서 예외가 날 수 있는 호출은 반드시 try 안에 있어야 하고, catch는 그 실패를 어떻게 다룰지만 적는다 — 새로운 다른 작업을 넣는 자리가 아니다. 

try {
    doSomethingThatMightFail();   // 예외 날 수 있는 코드는 여기
} catch (SomeException e) {
    handleTheFailure(e);          // 위에서 실패했을 때 할 일만 여기
}

throw vs throws

위치의미
throwmethod 본문 안실제로 예외 객체를 던지는 statement. throw new XxxException("메시지");
throwsmethod 시그니처이 method가 checked exception을 던질 수 있다고 컴파일러에게 선언. unchecked는 선언 필요 없음.

"All methods use the throw statement to throw an exception." / checked exception이 아니면 "the throws clause" 없이도 된다. — Oracle Java Tutorials — How to Throw Exceptions

custom exception 만들기

// unchecked — RuntimeException 상속
public class EmployeeNotFoundException extends RuntimeException {
    public EmployeeNotFoundException(String message) {
        super(message);
    }
}

// checked — Exception 상속
public class InvalidEmployeeDataException extends Exception {
    public InvalidEmployeeDataException(String message) {
        super(message);
    }
}

// 사용
public Employee findByIdOrThrow(Long id) {           // throws 선언 필요 없음 (unchecked)
    if (!store.containsKey(id)) {
        throw new EmployeeNotFoundException("id=" + id);
    }
    return store.get(id);
}

public void validateDepartment(String d) throws InvalidEmployeeDataException {  // 필수 (checked)
    if (d == null || d.isBlank()) {
        throw new InvalidEmployeeDataException("department is required");
    }
}

Catch or Specify Requirement

"Code that might throw certain exceptions must be enclosed by either of the following: A try statement that catches the exception. A method that specifies that it can throw the exception." — Oracle Java Tutorials — The catch or Specify Requirement
