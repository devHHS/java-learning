Class / Object / Constructor Cheatsheet

레슨 0003에서 압축

용어

용어뜻
class설계도. field(상태) + method(동작)를 정의
objectnew로 만든 class의 실체. 메모리에 존재
fieldclass 안에 선언된 변수. object의 상태
constructorclass와 이름이 같은 특별한 메서드. new 시점에 실행, 반환 타입 없음

기본 형태

public class Invoice {
    String status;
    int amountInCents;

    public Invoice(String status, int amountInCents) {
        this.status = status;           // this.필드 = object의 field
        this.amountInCents = amountInCents;
    }
}

Invoice inv = new Invoice("DRAFT", 15000);

this

parameter 이름과 field 이름이 같을 때만 필요. this.x = field, x = local parameter.

default constructor

  • constructor를 하나도 안 만들면 컴파일러가 인자 없는 constructor를 자동 생성.
  • constructor를 하나라도 직접 만들면 default constructor는 더 이상 자동 생성되지 않음.

constructor에서 invariant 강제하기

public Money(int amountInCents, String currency) {
    if (amountInCents < 0) {
        throw new IllegalArgumentException("amount must not be negative");
    }
    this.amountInCents = amountInCents;
    this.currency = currency;
}

잘못된 상태의 object가 애초에 생성되지 못하게 막는 것 — validation의 가장 원초적인 형태.

Quarkus/CDI 다리

@ApplicationScoped bean을 프록시로 감싸려면 CDI는 인자 없는 constructor가 필요하다. @Inject constructor만 만들고 no-arg를 빠뜨리면 배포 시점 에러.
