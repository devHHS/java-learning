Collections Cheatsheet

레슨 0009에서 압축

세 가지 비교

ListSetMap
순서보장됨보장 안 됨보장 안 됨 (HashMap 기준)
중복허용불허key는 불허, value는 허용
대표 구현체ArrayListHashSetHashMap
접근 방식index (get(0))포함 여부 (contains())key (get(key))

패턴

List<String> tags = new ArrayList<>();
tags.add("food");
tags.get(0);

Set<String> categories = new HashSet<>();
categories.add("전자제품");
categories.add("전자제품");   // 무시됨
categories.size();             // 1

Map<Integer, String> nameById = new HashMap<>();
nameById.put(1, "김철수");
nameById.get(1);                // "김철수"

고르는 기준

순서 유지 + 중복 허용 → List. 중복 제거만 필요 → Set. id로 빠른 조회 → Map.

0008과의 연결

List/Set/Map은 전부 interface다. ArrayList/HashSet/HashMap은 그 구현체(implementation)다 — 선언 타입(interface)과 실제 타입(구현체)이 다른 게 여기서도 그대로 적용된다.
